# Development ownership

This project has one active development checkout, maintained on ThinkBook. Other devices may run release files but do not keep editable source copies.

Before changing development machines, commit and push all reviewed source changes, back up private untracked inputs separately, clone on the destination, verify the commit and tests/build, then retire the old checkout and update the private project index.

Business Markdown and Canvas data stays in the user's Vault. Never publish personal data, credentials, local settings or migration backups. Install only main.js, manifest.json and styles.css, preserving data.json.
